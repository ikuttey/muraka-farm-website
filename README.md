# Muraka Farm website

Official static website for Muraka Farm, Dharavandhoo, Baa Atoll, Maldives.

## Local preview

Open this folder in Visual Studio Code and run `index.html` with Live Server.

## GitHub Pages

1. Upload the contents of this folder to the repository root.
2. Open the GitHub repository.
3. Go to Settings → Pages.
4. Select “Deploy from a branch.”
5. Select the `main` branch.
6. Select `/ (root)`.
7. Save.

No build command or package installation is required.

## Payment configuration

The PayPal donation and adoption-payment URLs have intentionally been left empty. Add only confirmed live PayPal URLs before enabling online payments.
